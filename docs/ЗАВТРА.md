## Шаг 1. Права IAM — НЕ НУЖНО, я ошибся

Вчера я просил добавить `cloudformation:*`, `application-autoscaling:*`
и `iam:CreateServiceLinkedRole`. **Забудьте, делать ничего не надо.**

Я читал файл `docs/aws-iam-policy.json`, а он не отражает реальность. По факту
`seo_user` входит в группу **Admins** с политикой `AdministratorAccess` —
прав хватает на всё. Проверено:

```
aws iam list-groups-for-user --user-name seo_user   →  Admins
                                                       AdministratorAccess
```

## Шаг 2. Домен — один запуск скрипта

Сам зарегистрировать не смог: среда блокирует операции, списывающие реальные деньги.
Всё остальное подготовлено — контакт регистранта собирается из данных вашего AWS-аккаунта,
WHOIS-приватность включена.

```bash
./scripts/ops/register-domain.sh checkdotnumber.com your-email@example.com +7.XXXXXXXXXX
```

Скрипт проверит доступность, покажет цену ($16/год), спросит подтверждение и дождётся
результата. Ничего не спишется, пока вы не введёте `y`.

**Важно, о чём стоит знать заранее:** в феврале на этом аккаунте уже была попытка
зарегистрировать `ez-dict.com`, и она **провалилась** с ответом «Contact AWS Support».
Если повторится то же самое — это не проблема скрипта, аккаунт не допущен к регистрации
доменов. Тогда либо кейс в AWS Support (service-domains / registration-issue),
либо просто купить домен у любого регистратора и делегировать NS в Route 53.

**После регистрации обязательно:** на `your-email@example.com` придёт письмо ICANN.
По ссылке надо кликнуть **в течение 15 дней**, иначе домен отключат.

Свободны на сейчас: `checkdotnumber.com`, `dotnumbercheck.com`, `frostdatefinder.com`,
`whenisfrost.com`, `myfrostdate.com`.

## Шаг 3. Ключ EC2 и разворачивание ($50/мес)

```bash
aws ec2 create-key-pair --key-name seo-platform \
  --query KeyMaterial --output text > ~/.ssh/seo-platform.pem
chmod 400 ~/.ssh/seo-platform.pem

aws cloudformation deploy \
  --template-file infra/single-host.yaml \
  --stack-name seo-platform-host \
  --capabilities CAPABILITY_IAM \
  --parameter-overrides \
      KeyPairName=seo-platform \
      DomainName=<домен> \
      HostedZoneId=<Z...> \
      SshAllowedCidr=$(curl -s ifconfig.me)/32
```

Hosted Zone ID после регистрации:

```bash
aws route53 list-hosted-zones --query "HostedZones[].{Name:Name,Id:Id}" --output table
```

## Шаг 4. USPTO — можно не спешить

Ключ вы вчера получить не смогли, и это ожидаемо: с 18 июня 2026 он выдаётся только
после верификации личности через **ID.me**, а та построена вокруг SSN и американской
кредитной истории. Для резидента Казахстана это, скорее всего, тупик.

Потеря небольшая. Товарные знаки — самая слабая из ниш, и в план развития они
всё равно не входят (см. [ПРОГНОЗ_ДОХОДА.md](ПРОГНОЗ_ДОХОДА.md)).

## Продукт для дорожки A готов

```bash
npx tsx scripts/export_new_carriers.ts --days 30 --state TX
```

Выдаёт CSV: **1 499 перевозчиков по Техасу за 30 дней, у 100% есть телефон.**
По США — 12 266 за месяц. Это то, что продаётся страховым агентствам:
каждый новый DOT-номер обязан оформить страховку.

Это можно начинать продавать **до** того, как появится домен и сайт —
выгрузка отправляется письмом.

## Второй продукт тоже готов (сделан в ночь на 14.09)

```bash

```

**38 974 новых компании за 30 дней** из Колорадо, Нью-Йорка и Коннектикута,

расчёт зарплаты, банк, бухгалтерию, POS, сайт, телефонию, рекламу.
То есть один набор данных — восемь разных типов покупателей.

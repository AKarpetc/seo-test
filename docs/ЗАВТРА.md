## Шаг 1. DNS для stormsthathit.com — единственное, что блокирует сайт

Сайт выложен (14 441 страница), домен привязан к проекту, но записей в DNS нет:
токен агента не имеет прав на зону.

Cloudflare → Workers & Pages → проект `storms-that-hit` → вкладка **Custom domains**.
Там уже висят `stormsthathit.com` и `www.stormsthathit.com` со статусом Pending.
Открыть каждый — Cloudflare предложит создать DNS-запись сам, согласиться.

Если не предлагает — домен `stormsthathit.com` → **DNS** → Add record, две записи,
у обеих прокси включён (оранжевое облако):

```
Type CNAME   Name @     Target storms-that-hit.pages.dev
Type CNAME   Name www   Target storms-that-hit.pages.dev
```

Через несколько минут статус станет Active, сертификат выпустится сам.

**Проверка:** открыть https://stormsthathit.com/storms/houston-tx — должна быть
страница «Hurricanes and Tornadoes That Hit Houston, TX».

Если старый дашборд не показывает проект, прямой адрес:
`https://dash.cloudflare.com/f29eee344264b6bfda92414789aed0a8/pages/view/storms-that-hit`

## Шаг 2. Сказать агенту, что домен открылся

Агент отправит страницы в IndexNow. Сейчас IndexNow отвечает 403
`SiteVerificationNotCompleted`: он не может забрать файл ключа с домена, который
не резолвится. Команда, если захотите сами:

```
npm run indexnow -- --dir static/storms --host stormsthathit.com
```

## Шаг 3. Search Console

Добавить ресурс типа **Domain** для `stormsthathit.com`, подтвердить TXT-записью
в том же DNS, отправить sitemap **полным адресом**:

```
https://stormsthathit.com/sitemap.xml
```

Короткая форма `sitemap.xml` для ресурса типа Domain не принимается.

## Шаг 4. Аналитика

Проект `storms-that-hit` → вкладка **Metrics** → Web Analytics → **Enable**.
Кода не нужно, Cloudflare вставляет счётчик сам, как на первых двух сайтах.
`NEXT_PUBLIC_ANALYTICS_ENABLED=1` уже стоит в `.env`, политика об этом пишет.

## Шаг 5. Дальше не трогать 3–4 недели

Ни повторных sitemap, ни правок шаблонов. На новом домене краулинговый бюджет
выдаётся медленно, повторная отправка ничего не ускоряет.

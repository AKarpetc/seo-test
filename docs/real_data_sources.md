# Реальные источники данных для Programmatic SEO (США)

Здесь собраны лучшие открытые и платные источники данных для наших трех ниш. Любой из этих источников мы можем подключить к нашему скрипту `prisma/seed.ts` или написать отдельный Python-парсер для массовой загрузки.

---

## 1. Ниша: Автомобили (Характеристики, MPG, Двигатели)

Для генерации тысяч страниц вида *"2023 Toyota Camry Specs & MPG"* вам нужны полные базы данных автомобилей.

### Бесплатные источники
1. **[Fueleconomy.gov (EPA) API](https://www.fueleconomy.gov/feg/ws/index.shtml)**
   - **Описание:** Официальная база данных правительства США по расходу топлива. Содержит марку, модель, год, объем двигателя, цилиндры и MPG (расход в городе/на трассе).
   - **Формат:** XML/JSON (REST API) или скачиваемый CSV.
   - **Идеально для:** Быстрого старта, так как данные 100% точны и бесплатны.
2. **[NHTSA vPIC API](https://vpic.nhtsa.dot.gov/api/)**
   - **Описание:** База Министерства транспорта США. Огромный список всех существующих марок и моделей авто по годам.
   - **Минус:** Нет детальных характеристик типа лошадиных сил, только базовая инфа и VIN-декодер.

### Платные / Freemium (через RapidAPI)
1. **[Car API (на RapidAPI)](https://rapidapi.com/principalapis/api/car-data)**
   - **Описание:** Очень мощное API, отдает полные характеристики: габариты, вес, тип привода, мощность, разгон до 100 км/ч.
   - **Стоимость:** Есть бесплатный лимит (например, 100 запросов в день), далее от $10-20 в месяц.

## 2. Ниша: Зарплаты по профессиям и штатам США

Самая прибыльная ниша. Страницы вида *"Average Dental Assistant Salary in Austin, TX"*.

### Бесплатные источники
1. **[US Bureau of Labor Statistics (BLS.gov)](https://www.bls.gov/developers/)**
   - **Описание:** Официальная статистика США. Отдел OES (Occupational Employment and Wage Statistics) ежегодно публикует зарплаты по каждой профессии с разбивкой по каждому городу и штату.
   - **Формат:** Открытый API и возможность выгрузить гигантские CSV/Excel таблицы (на сотни тысяч строк).
   - **Идеально для:** Это Святой Грааль для сайтов о зарплатах в США. Данные абсолютно бесплатны и достоверны.
2. **[Kaggle: Data Science & STEM Salaries](https://www.kaggle.com/datasets)**
   - **Описание:** На Kaggle есть множество готовых CSV-файлов с зарплатами программистов, врачей, учителей. Достаточно вбить в поиск "US Salaries".

### Платные источники
1. **[Salary API (RapidAPI)](https://rapidapi.com/search/salary)**
   - **Описание:** Агрегаторы, которые собирают данные с Glassdoor и Indeed. Стоят денег, но данные обновляются в реальном времени.

## 3. Ниша: Погода и Климат (Путеводители)

Страницы вида *"Weather in Miami, FL: Best Time to Visit & Climate"*.

### Бесплатные источники
1. **[Open-Meteo Historical Weather API](https://open-meteo.com/en/docs/historical-weather-api)**
   - **Описание:** Одно из лучших бесплатных погодных API в мире. Позволяет получить среднюю температуру, количество осадков и дождливых дней для ЛЮБОЙ точки мира (по координатам) за последние 80 лет.
   - **Лимиты:** До 10,000 запросов в сутки бесплатно. Коммерческая лицензия недорогая.
2. **[NOAA Climate Data Online](https://www.ncdc.noaa.gov/cdo-web/webservices/v2)**
   - **Описание:** Национальное управление океанических и атмосферных исследований США.
   - **Формат:** API отдает точные исторические данные по каждому городу США. Бесплатно по токену.

### Платные источники
1. **[WeatherAPI](https://www.weatherapi.com/)**
   - **Описание:** Очень удобное API, которое, помимо прогнозов, отдает климатические нормы (Climate Averages) — средняя температура днем/ночью по месяцам для любого города.
   - **Стоимость:** Бесплатно до 1 млн запросов в месяц, полная история — платно.

## План действий: Как мы будем это использовать?
Если вы выберете одну из ниш (например, **Автомобили** через *Fueleconomy.gov*), наш алгоритм будет следующим:
1. Мы скачиваем их CSV-базу или пишем скрипт, который делает запросы к их API.
2. Скрипт-сидер (`prisma/seed.ts`) проходит по всем данным, чистит их (например, переводит MPG в удобный формат, генерирует SEO-текст-описание) и складывает в наш PostgreSQL.
3. Next.js автоматически генерирует на основе этих данных тысячи красивых страниц.

# Состояние проекта — передача в новую сессию

Обновлено 14.09.2026.

---

## Что это за проект

Программатик-SEO на открытых данных правительства США. Одна страница на запись,
статическая выкладка на Cloudflare Pages.

**Цель пересматривалась дважды, текущая формулировка:** окупить инфраструктуру
и проверить, есть ли спрос. Владелец **не готов заниматься продажами** — ни звонков,
ни писем. Это решение принято осознанно и пересматривать его не нужно.

Следствие: B2B-направления (продажа данных о перевозчиках и новых компаниях)
построены, но **не запускаются**. Остаётся только SEO с рекламной монетизацией.

## Что осталось — по владельцу

1. **Залить репозиторий на GitHub.** Всё закоммичено, история вычищена от секретов,
   `gh` установлен. Осталось:
   ```
   gh auth login
   gh repo create seo-data-platform --private --source=. --remote=origin --push
   ```
   Агент это сделать не может: среда блокирует доступ к keychain, а `gh auth login`
   требует браузера.

2. **Выложить сайты.** `npm run publish -- frost`, затем привязать домен
   в панели Cloudflare (Workers & Pages → проект → Custom domains).
   Инструкция: [КАК_ВЫЛОЖИТЬ.md](КАК_ВЫЛОЖИТЬ.md).

3. **Search Console** для каждого домена, отправить `sitemap.xml`, **не трогать 3–4 недели**.

4. **Ротировать ключ AWS** — у текущего права `ec2:*`, `rds:*`, `iam:CreateRole`.
   Завести отдельный ETL-ключ только на `s3:*` по бакетам `seo-pr-*`.

5. **Опционально:** ключи USPTO и FCC. USPTO требует верификации через ID.me,
   которая для резидента Казахстана скорее всего недоступна. Потеря небольшая.

## Что осталось — по агенту

Ничего блокирующего. Возможные следующие шаги, по убыванию ценности:

1. **Качество воды** — новая ниша, конкуренция очень низкая. Данные проверены:
   EPA отдаёт 97 110 водоканалов без ключа. Нужна агрегация по городам,
   иначе получатся страницы про безымянные водопроводные системы. ~2 дня.
2. **Риск затопления** (FEMA) — высокий RPM, рядом страхование. Данные проверены.
3. **Актёры на Apify** из готовых конвейеров FMCSA и реестров компаний —
   единственный канал дохода без продаж и без ожидания индексации.
   Медиана по площадке $470/мес, топ $5–20k.

## Решения, которые НЕ надо пересматривать

- **Не публиковать 12 млн страниц справочников.** Это ровно тот паттерн, который
  политика Google scaled content abuse называет и обнуляет.
- **Не брать десятки доменов.** Новый домен зреет 4–8 месяцев; в одиночку
  реально вести 2–3 SEO-сайта.
- **Не разносить одну тему по двум доменам.** ZIP-страницы и страницы по станциям
  отвечают на один вопрос — они на одном домене, лишнее отфильтровано по населению.
- **Не разворачивать EC2.** Шаблоны в `infra/` валидны, но при статике сервер не нужен.
  Стоимость упала с ~$50/мес до цены домена.
- **Не заниматься B2B-продажами.** Владелец отказался.

## Грабли, на которые уже наступали

Все исправлены, но при работе с этими источниками они вернутся:

| Источник | Подвох |
|---|---|
| FAA | отдаёт 403 без браузерного User-Agent |
| NHTSA | «отзывов нет» приходит как HTTP **400** с валидным пустым телом |
| NOAA | даты заморозков — строки `MM/DD`, не день года |
| FDIC | переехал на `api.fdic.gov`; `locations` даёт 78k отделений, `institutions` — 4.5k |
| USPTO | `bulkdata.uspto.gov` больше не резолвится |
| Census | без ключа отдаёт `missing_key.html`, `www2.census.gov` блокирует по UA |
| USDA зоны | **нельзя** вывести из средней минимальной температуры NOAA — только `phzmapi.org` |
| Socrata | `$where` по датам, сквозная пагинация ограничена |

Хелпер `toInt` раньше срезал точку и превращал `"204.0"` в `2040` — исправлено
в `scripts/lib/etl.ts`, но при добавлении источников стоит проверять значения глазами,
а не только факт парсинга.

**Статическая выкладка:** домен зашивается на этапе сборки (canonical и название сайта
попадают в HTML). Сборка с чужим origin = 18 686 страниц со ссылками на чужой домен.
`npm run publish` выставляет всё сам.

## Честный прогноз

Октябрь–декабрь — индексация, доход $0. Февраль–апрель — сезон заморозков,
15–60 тыс. визитов, $120–500/мес. Окупаемость домена ($1.33/мес) — почти наверняка
к февралю.

Вероятность, что сезон даст больше $100/мес — 40–45%. Что проект не взлетит — 35%.

**Точка принятия решения — май 2027**, после сезона. Раньше данных не будет.

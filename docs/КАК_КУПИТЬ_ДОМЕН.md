# Как купить домен — пошагово

Проверено 14.09.2026.

---

## Где покупать: Cloudflare Registrar

Раньше я предлагал Route 53. **Теперь это неправильный выбор**, и по двум причинам:

1. Хостинг переехал на Cloudflare Pages. Домен, купленный в Cloudflare, сразу
   в нужной панели — никакой возни с переносом NS-серверов.
2. На вашем AWS-аккаунте регистрация домена **уже один раз провалилась**
   (`ez-dict.com`, февраль 2026, ответ «Contact AWS Support»). Нет смысла
   наступать на те же грабли.

### Сравнение цен на `.com`

| Регистратор | Первый год | Продление | Приватность WHOIS |
|---|---:|---:|---|
| **Cloudflare Registrar** | **$10.46** | **$10.46** | бесплатно |
| Porkbun | $11.08 | $11.08 | бесплатно |
| Namecheap | $10.98 | **$18.48** | бесплатно |
| AWS Route 53 | $16.00 | $16.00 | бесплатно |

Обратите внимание на Namecheap: дёшево первый год, а дальше почти вдвое дороже.
За пять лет разница с Cloudflare — около $40 на каждый домен. Мелочь на одном,
но мы планируем 6–8.

Cloudflare продаёт домены **по себестоимости**: оптовая цена реестра плюс сбор
ICANN, без наценки. Заработать на этом они не пытаются — им нужно, чтобы вы
пользовались их сетью.

**Единственное ограничение Cloudflare:** домен обязан использовать их
NS-серверы, переключить на чужой DNS нельзя. Для нас это не ограничение,
а именно то, что нужно — сайт и так будет на Cloudflare Pages.

Осенью 2026 Verisign поднимает оптовую цену `.com`; Cloudflare передаст
повышение как есть, будет около $11.17.

## Какое имя брать

Свободны на сегодня (проверял через API Route 53):

| Домен | Комментарий |
|---|---|
| **`frostdatefinder.com`** | **моя рекомендация** — прямо описывает действие, легко читается вслух |
| `whenisfrost.com` | короче, но звучит как вопрос, хуже для бренда |
| `myfrostdate.com` | «my» в домене выглядит слабее |
| `frostcalendar.com` | шире по смыслу, если захотите добавить посевной календарь |

Занято, даже не пробуйте: `frostdates.com`, `firstfrost.com`, `frostmap.com`,
`plantingdate.com`, `frostdatebyzip.com`, `growingseasons.com`.

**Про точные вхождения ключевых слов:** домен вида `frostdatebyzip.com` не даёт
преимущества в ранжировании — Google отменил этот фактор больше десяти лет назад.
Выбирайте по запоминаемости, а не по ключевым словам.

Второй домен, под отзывы авто, подберём отдельно — там другая тема и торопиться
с ним не нужно.

## Пошагово

### Шаг 1. Аккаунт Cloudflare

1. Открыть https://dash.cloudflare.com/sign-up
2. Ввести почту и пароль. Карта на этом шаге не нужна.
3. **Подтвердить почту по ссылке из письма.** Без подтверждённого адреса
   регистратор не даст купить домен — это требование ICANN, не Cloudflare.

### Шаг 2. Покупка

1. В панели слева: **Domain Registration → Register Domains**
2. Ввести `frostdatefinder` в поиск
3. Напротив свободного домена нажать **Purchase**
4. Срок регистрации: **1 год**. Больше брать не надо — проект ещё не проверен,
   а продлить всегда успеете
5. Заполнить контакты. Требования Cloudflare:
   - **только латиница**, кириллица не принимается
   - имя и фамилия — минимум по две буквы
   - телефон — с кодом страны, только цифры: `+7 XXXXXXXXXX`
   - адрес не может состоять из одних цифр
   - индекс в корректном формате
6. Оплата картой. Регистрация занимает до 30 секунд.

### Шаг 3. Обязательное подтверждение ICANN

После покупки на почту придёт письмо от Cloudflare или ICANN со ссылкой
подтверждения.

**Нажать на неё нужно в течение 15 дней.** Если этого не сделать, домен
принудительно отключат — и деньги не вернут. Это самая частая причина, по которой
у людей «купленный домен не работает».

### Шаг 4. Сказать мне

Домен появится в Cloudflare автоматически, отдельно добавлять сайт не нужно —
это преимущество покупки прямо там.

Напишите мне имя домена, и я выложу сайт: 18 687 страниц уже собраны и ждут.

## Если карта не проходит

Оплата из Казахстана иногда не проходит у зарубежных сервисов. Если Cloudflare
откажет:

1. **Porkbun** — $11.08/год, принимает больше типов карт, поддерживает PayPal.
   После покупки нужно будет вручную прописать NS-серверы Cloudflare
   (я подскажу, какие именно, это две строки).
2. **Namecheap** — работает почти везде, но помните про продление $18.48.

Оба варианта рабочие, просто на один шаг длиннее.

## Чего НЕ надо делать

- **Не покупать сразу несколько доменов.** Второй сайт будет через 1.5–2 месяца,
  а платить за домен начнёте с момента покупки.
- **Не брать защиту WHOIS за деньги.** У всех троих она бесплатна. Если её
  предлагают платно — вы не на том сайте.
- **Не соглашаться на хостинг, почту и SSL в довесок.** Ничего из этого не нужно:
  хостинг у нас Cloudflare Pages бесплатно, SSL там же автоматически.
- **Не брать домен на 5–10 лет** ради скидки. Проект не проверен,
  решение о продолжении — в мае 2027.
- **Не использовать `scripts/ops/register-domain.sh`.** Он писался под Route 53
  и теперь не актуален.

# Как выложить сайты

Оба домена куплены, оба сайта собраны. Осталось развернуть.

| Сайт | Домен | Страниц | Проект Cloudflare |
|---|---|---:|---|
| Заморозки | `frostdatefinder.com` | 18 686 | `frost-date-finder` |
| Отзывы авто | `checkcarrecalls.com` | 6 654 | `check-car-recalls` |

---

## Шаг 1. Установить wrangler и войти — один раз

```bash
npm install -g wrangler
wrangler login
```

`wrangler login` откроет браузер. Разрешите доступ тому же аккаунту Cloudflare,
где лежат домены.

Проверить, что вошли:

```bash
wrangler whoami
```

---

## Шаг 2. Выложить первый сайт

```bash
cd /Users/artyomkarpets/seo
npm run publish -- frost
```

Скрипт сам: соберёт приложение с нужным доменом, поднимет локальный сервер,
отрендерит 18 686 страниц, проверит лимит в 20 000 файлов и зальёт в Cloudflare.

Занимает 5–10 минут: сборка быстрая, а вот заливка ~500 МБ зависит от канала.

Если хотите сначала посмотреть без заливки:

```bash
npm run publish -- frost --dry-run
```

---

## Шаг 3. Привязать домен — только при первой заливке

Cloudflare выложит сайт на служебный адрес вида `frost-date-finder.pages.dev`.
Чтобы работал ваш домен:

1. Панель Cloudflare → **Workers & Pages** → проект `frost-date-finder`
2. Вкладка **Custom domains** → **Set up a custom domain**
3. Ввести `frostdatefinder.com` → **Continue** → **Activate domain**

DNS-запись создастся сама — домен уже в этом аккаунте. Сертификат HTTPS
выпустится автоматически, обычно за пару минут.

Повторить для `www.frostdatefinder.com`, если хотите, чтобы работал и такой адрес.

## Шаг 4. Второй сайт


И то же самое в панели: проект `check-car-recalls`, домен `checkcarrecalls.com`.

## Шаг 5. Search Console

Для **каждого** домена отдельно:

1. https://search.google.com/search-console → **Add property** → **Domain**
2. Ввести домен → Google даст TXT-запись
3. В Cloudflare: домен → **DNS** → **Add record** → тип `TXT`, имя `@`,
   значение из Google → Save
4. Вернуться в Google → **Verify**
5. **Sitemaps** → отправить `sitemap.xml`

Дальше **не трогать 3–4 недели.** Смотреть отчёт «Страницы»:

- проиндексировано больше 30% — хорошо;
- меньше 10% — расширяться нельзя, проблема в качестве страниц.

## Что проверить сразу после выкладки

```bash
curl -sI https://frostdatefinder.com | head -3
curl -s https://frostdatefinder.com/robots.txt
curl -s https://frostdatefinder.com/frost/frost-dates-11226-brooklyn-ny | grep -o '<title>[^<]*</title>'
```

Должно быть:

- бесхостовый адрес отдаёт редирект 301 на `/frost`;
- `robots.txt` содержит `Allow: /` и ссылку на sitemap;
- в заголовке страницы — `Frost Dates for 11226 (Brooklyn, NY)`.

Если `robots.txt` говорит `Disallow: /` — сборка прошла без
`NEXT_PUBLIC_ALLOW_INDEXING=true`. Скрипт выставляет её сам, так что
такого быть не должно, но проверить стоит: с этим флагом сайт не попадёт в индекс вообще.

## Обновление сайта потом

Та же команда. Cloudflare Pages хранит историю деплоев, откатиться можно в панели.

```bash
npm run publish -- frost
```

Данные обновляются отдельно, до выкладки:

```bash
npm run load:climate && npm run load:zipclimate   # заморозки
npm run load:recalls                              # отзывы авто
```

NOAA обновляет нормали раз в десять лет, так что заморозки трогать не нужно.
NHTSA добавляет отзывы постоянно — раз в месяц имеет смысл.

## Если что-то пошло не так

**`wrangler: command not found`** — установка не прописалась в PATH.
Использовать `npx wrangler` вместо `wrangler`.

**Заливка обрывается** — Cloudflare дозаливает только изменённое,
просто запустите команду ещё раз.

**Домен не открывается через 10 минут** — проверьте в **Custom domains**,
что статус `Active`, а не `Pending`. Если висит — удалить и добавить заново.

**Ошибка про лимит файлов** — скрипт проверяет её до заливки.
Поднять порог населения: `FROST_MIN_POPULATION=5000 npm run publish -- frost`.

# Руководство по развертыванию на AWS (EC2 + Docker)

Так как у вас локально не установлен AWS CLI, процесс переноса нашего локального приложения на сервера Amazon (Phase 4) потребует от вас нескольких кликов в панели управления AWS.

Мы упаковали наше приложение в **Docker** и **Docker Compose**. Это значит, что вам не нужно будет настраивать Nginx, устанавливать Node.js или базу данных на сервере вручную. Все запустится одной командой!

## Шаг 1: Запуск сервера (EC2)
1. Зарегистрируйтесь / Войдите в консоль [AWS Management Console](https://aws.amazon.com/console/).
2. Перейдите в сервис **EC2** и нажмите **Launch Instance**.
3. Укажите название (например, `seo-platform`).
4. **ОС:** Выберите `Ubuntu 22.04 LTS` или `24.04 LTS`.
5. **Тип инстанса:** `t3.micro` или `t4g.small` (t4g дешевле и быстрее, если выбираете его, выберите Ubuntu ARM-архитектуру).
6. **Key Pair (Ключ):** Создайте новый `.pem` ключ и скачайте его. Он нужен для подключения по SSH.
7. **Network settings:** Поставьте галочки:
   - Allow SSH traffic from (Anywhere)
   - Allow HTTP traffic from the internet (Важно!)
   - Allow HTTPS traffic from the internet
8. Нажмите **Launch instance**.

## Шаг 2: Установка Docker на сервер
Откройте терминал на вашем Mac и подключитесь к серверу по SSH (подставьте ваш IP-адрес из панели AWS и путь к скачанному `.pem` ключу):

```bash
chmod 400 ~/Downloads/ваш-ключ.pem
ssh -i "~/Downloads/ваш-ключ.pem" ubuntu@ВАШ_IP_АДРЕС
```

Оказавшись на сервере, выполните установку Docker:
```bash
sudo apt update -y
sudo apt install docker.io docker-compose -y
sudo usermod -aG docker $USER
```
*(После этого отключитесь от сервера `exit` и подключитесь заново, чтобы права применились).*

## Шаг 3: Копирование файлов на сервер
Теперь вам нужно перекинуть папку `seo` с вашего Mac на сервер AWS. Откройте новый терминал на Mac и выполните (находясь в папке над проектом `seo`):

```bash
scp -i "~/Downloads/ваш-ключ.pem" -r /Users/artyomkarpets/seo ubuntu@ВАШ_IP_АДРЕС:~/seo
```

## Шаг 4: Запуск проекта
Снова подключитесь к серверу по SSH:
```bash
ssh -i "~/Downloads/ваш-ключ.pem" ubuntu@ВАШ_IP_АДРЕС
cd seo
```

Теперь, когда вы в папке проекта на сервере, запустите магию Docker:
```bash
docker-compose up -d --build
```

**Что произойдет?**
1. Docker скачает образ PostgreSQL и запустит изолированную базу данных.
2. Docker соберет ваше Next.js приложение.
3. Приложение подключится к PostgreSQL и запустится на 80 порту (HTTP).

## Шаг 5: Инициализация БД (На сервере)
База пустая, нужно накатить структуру и тестовые данные (Seed). Выполните прямо на сервере:
```bash
# Применяем схему к боевой базе PostgreSQL
docker-compose exec web npx prisma db push

# Запускаем скрипт-сидер, чтобы наполнить базу нашими тематиками
docker-compose exec web npx tsx prisma/seed.ts
```

**Готово!** Вбейте в браузере IP-адрес вашего сервера (например, `http://3.124.55.22`), и вы увидите свой сайт, работающий в интернете! В дальнейшем останется только привязать красивый домен через AWS Route 53.

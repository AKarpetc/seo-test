# Как получить API-ключи

Четыре справочника построены, но пустые — источники закрыты ключами. Код загрузчиков
пишется под ключ за пару часов, сами ключи получаете вы.

Порядок — по соотношению «польза / время».

---

## 1. Census ACS — демография по ZIP (2 минуты, бесплатно)

Самый ценный из четырёх: данные Census перемножаются с уже загруженными и дают
низкочастотные запросы, которых нет ни у кого.

1. Открыть https://api.census.gov/data/key_signup.html
2. Заполнить: Organization Name (можно личное имя), Email
3. Нажать Submit — ключ приходит на почту в течение минуты
4. В письме будет ссылка «activate» — по ней надо кликнуть, иначе ключ не работает
5. Записать в `.env`:

```
CENSUS_API_KEY="ваш-ключ"
```

Проверить, что ключ живой:

```bash
curl "https://api.census.gov/data/2023/acs/acs5?get=NAME,B01003_001E&for=state:*&key=ВАШ_КЛЮЧ" | head -c 200
```

Должен вернуться JSON-массив. Если приходит HTML со словом `missing_key` — ключ
не активирован, нажмите ссылку из письма.

Лимиты: 500 запросов в день без ключа, с ключом — без жёсткого лимита.

---

## 2. EIA — тарифы на электричество (2 минуты, бесплатно)

1. Открыть https://www.eia.gov/opendata/register.php
2. Ввести email → на почту приходит ключ (32 символа)
3. Записать в `.env`:

```
EIA_API_KEY="ваш-ключ"
```

Проверить:

```bash
curl "https://api.eia.gov/v2/electricity/retail-sales/data/?api_key=ВАШ_КЛЮЧ&frequency=annual&data[0]=price&facets[sectorid][]=RES&length=5"
```

Лимит: 5000 запросов в час.

## 3. USPTO — товарные знаки (нужна верификация личности, может не получиться)

Раздел API в кабинете называется **Open Data Portal** — левое меню, в самом низу,
под заголовком «PRODUCT SPECIFIC INFORMATION». Прямая ссылка: https://data.uspto.gov/apikey

**Но ключ не выдадут, пока не пройдены два шага в том же меню:**

1. **Multifactor Authentication (MFA)** — обязательно, без этого доступ к аккаунту теряется.
2. **ID verification** — верификация личности через ID.me.

С 18 июня 2026 доступ к Open Data Portal требует подтверждённого аккаунта USPTO.gov,
а ключ выдаётся только после верификации через ID.me.

### Подводный камень для нерезидентов США

Процедура ID.me в USPTO построена вокруг SSN и американской кредитной истории.
ID.me в принципе умеет верифицировать по иностранному паспорту с подтверждением
зарубежного адреса, но именно поток USPTO для лиц, домицилированных вне США,
ограничен — там требуется представитель, американский патентный поверенный.

Итог: **если у вас нет SSN и адреса в США, ключ вы, скорее всего, не получите
самостоятельно.** Проверить это можно, открыв «ID verification» в левом меню —
там сразу будет видно, какие варианты предлагаются.

### Ещё одно требование

С 18 августа 2026 USPTO требует заполнить четыре дополнительных поля профиля.
Не заполнены — доступ к Open Data Portal и ключу отзывается.

### Стоит ли вообще этим заниматься

Из четырёх ключей этот — самый трудоёмкий и наименее ценный. Ниша товарных знаков
конкурентная, а сам massively-scaled SEO-план по ней отдельно не оправдан
(см. [АНАЛИЗ_ПРИБЫЛЬНОСТИ.md](АНАЛИЗ_ПРИБЫЛЬНОСТИ.md)).

Рекомендую сначала взять **Census и EIA** — по 2 минуты каждый, без верификации личности,
и пользы от них кратно больше. К USPTO вернуться, если вообще решим делать эту нишу.

## 4. FCC Broadband — интернет-провайдеры (дольше всех)

Самый закрытый источник: публичного файла нет, только выгрузка из-под логина.

1. Открыть https://broadbandmap.fcc.gov/data-download
2. Создать аккаунт FCC (нужен CORES FRN — регистрация организации)
3. Скачать National Broadband Data вручную, файлы на несколько ГБ
4. Положить файл в бакет: `aws s3 cp <файл> s3://seo-pr-broadband-f40558/`

Из-за трудоёмкости регистрации это последний в очереди. Если не хочется возиться —
эту нишу можно просто не делать, потеря небольшая.

## Что делать после получения ключей

Прислать мне — допишу загрузчики (`scripts/load_demographics.ts`, `scripts/load_energy.ts`)
и залью данные. Ключи в репозиторий не попадут: `.env` в `.gitignore`, проверено.

Если присылать ключи в переписке не хочется — впишите их в `.env` сами, я напишу код
так, чтобы он просто читал переменные окружения, и мне значения видеть не обязательно.

# Домен — что я сделал и что нужно от вас

## Могу ли я зарегистрировать сам

**Нет, и вот почему.** Регистрация домена — это списание с вашей карты, обязательство
на год и операция без отмены: домены не возвращают и не рефандят. Плюс само имя —
решение о бренде, а не техническая деталь. Такое я за вас не решаю.

AWS CLI установлен и настроен (проверено: `aws sts get-caller-identity` отвечает от имени
`seo_user`, аккаунт <AWS_ACCOUNT_ID>), так что после вашего выбора регистрация — одна команда.

## Свободные варианты (проверил через Route 53 сегодня)

Под дорожку с заморозками (SEO-эксперимент):

| Домен | Статус |
|---|---|
| `frostdatefinder.com` | свободен |
| `whenisfrost.com` | свободен |
| `myfrostdate.com` | свободен |

Под дорожку с перевозчиками (B2B):

| Домен | Статус |
|---|---|
| `checkdotnumber.com` | свободен |
| `dotnumbercheck.com` | свободен |

Занято и даже не пытайтесь: `frostdates.com`, `carrierlookup.com`, `usdotlookup.com`,
`plantingdates.com`, `truckauthority.com`, `growingseason.com`.

Проверить любой другой вариант:

```bash
aws route53domains check-domain-availability --region us-east-1 --domain-name ваш-вариант.com
```

Учтите: точные совпадения с запросом (exact-match domain) давно не дают преимущества
в ранжировании. Имя выбирайте по запоминаемости, а не по ключевым словам.

## Как зарегистрировать

**Через консоль (проще):** AWS Console → Route 53 → Registered domains → Register domains.
`.com` стоит около $14/год. Hosted zone создаётся автоматически.

**Через CLI:** нужен JSON с контактными данными — по желанию подготовлю.

## Что прислать мне после

```bash
aws route53 list-hosted-zones --query "HostedZones[].{Name:Name,Id:Id}" --output table
```

Нужны имя домена и Hosted Zone ID (`Z...`). Дальше деплой — одна команда:

```bash
aws cloudformation deploy \
  --template-file infra/single-host.yaml \
  --stack-name seo-platform-host \
  --capabilities CAPABILITY_IAM \
  --parameter-overrides \
      KeyPairName=<ваш-ключ> \
      DomainName=<домен> \
      HostedZoneId=<Z...> \
      SshAllowedCidr=$(curl -s ifconfig.me)/32
```

Перед этим нужен EC2 key pair:

```bash
aws ec2 create-key-pair --key-name seo-platform --query KeyMaterial --output text > ~/.ssh/seo-platform.pem
chmod 400 ~/.ssh/seo-platform.pem
```

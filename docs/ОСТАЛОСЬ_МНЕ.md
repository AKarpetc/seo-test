## Ваши шаги

### Шаг 1. Домен — 10 минут

Раз дорожка теперь SEO, домен нужен под заморозки, а не под перевозчиков.
Свободны (проверял 13.09):

- `frostdatefinder.com`
- `whenisfrost.com`
- `myfrostdate.com`

**Покупать в Cloudflare Registrar, не в AWS** — $10.46/год против $16, и домен
сразу в той панели, где стоит хостинг. Подробная инструкция:
[КАК_КУПИТЬ_ДОМЕН.md](КАК_КУПИТЬ_ДОМЕН.md).

Скрипт `scripts/ops/register-domain.sh` писался под Route 53 и больше не актуален.

**Помните:** в феврале попытка зарегистрировать `ez-dict.com` на этом аккаунте
**провалилась** с ответом «Contact AWS Support». Если повторится — аккаунт
не допущен к регистрации, и проще купить домен у любого регистратора
(Namecheap, Porkbun) и указать DNS Cloudflare.

**После регистрации:** на `your-email@example.com` придёт письмо ICANN.
Кликнуть по ссылке в течение 15 дней, иначе домен отключат.

### Шаг 2. Аккаунт Cloudflare — 5 минут

1. Зарегистрироваться на https://dash.cloudflare.com/sign-up (бесплатно, карта не нужна).
2. Добавить домен: Add a site → ввести домен → выбрать **Free**.
3. Cloudflare покажет два NS-сервера. Их надо прописать у регистратора:
   - если домен в Route 53: Route 53 → Registered domains → домен → Add or edit name servers;
   - если у другого регистратора — в его панели.
4. Подождать до 24 часов, пока DNS разойдётся.

### Шаг 3. Выложить сайт — одна команда

```bash
npm install -g wrangler
wrangler login              # откроет браузер, разрешить доступ

npm run build
npx next start -p 3100 &
npm run static -- --section climate --origin http://localhost:3100
npx wrangler pages deploy static/climate --project-name frost-dates
```

В панели Cloudflare: Workers & Pages → проект → Custom domains → привязать домен.

**Перед сборкой не забыть** выставить настоящий домен, иначе в HTML запекутся
ссылки на localhost:

```bash
export NEXT_PUBLIC_SITE_URL=https://frostdatefinder.com
export NEXT_PUBLIC_ALLOW_INDEXING=true
```

### Шаг 4. Google Search Console — 15 минут

1. https://search.google.com/search-console → Add property → Domain → ваш домен.
2. Подтверждение через DNS TXT-запись (добавляется в Cloudflare одной строкой).
3. Sitemaps → отправить `sitemap.xml`.
4. **Дальше не трогать 3–4 недели.** Смотреть отчёт «Страницы»:
   - индексируется больше 30% — хорошо, можно расширяться;
   - меньше 10% — расширяться нельзя, проблема в качестве.

### Шаг 5. AdSense — когда появится трафик

Подавать заявку **не сразу**, а когда будет хотя бы 500–1000 посетителей в месяц:
на пустой сайт AdSense отвечает отказом, а повторная заявка идёт дольше.
Ориентировочно это декабрь–январь.

Ezoic в феврале 2026 поднял минимум до 250 000 пользователей в месяц,
Mediavine требует 50 000 сессий — оба нам недоступны в первый год.
Поэтому AdSense, $3–8 RPM.

## Чего делать НЕ надо

- **Не покупать десятки доменов.** При SEO-дорожке каждый домен требует
  6–12 месяцев на набор доверия. Один домен, один сезон — это и есть проверка.
- **Не разворачивать EC2.** Шаблоны в `infra/` остаются на случай, если проект
  пойдёт, но сейчас платить $50/мес не за что.
- **Не публиковать врачей, перевозчиков и остальные 12 млн страниц.** Это прямой
  путь под scaled content abuse и риск утащить за собой весь домен.
- **Не добавлять новые источники данных.** Их и так больше, чем мы используем.

## Честный прогноз по этой дорожке

| Когда | Что ожидать |
|---|---|
| Октябрь–декабрь | Индексация. Трафик 0–500/мес. Доход $0 |
| Январь | Первые запросы про заморозки. 1–3 тыс./мес |
| **Февраль–апрель** | **Сезон. 15–60 тыс./мес. $120–500/мес** |
| Май–август | Спад. 2–8 тыс./мес. $20–80/мес |

**Окупаемость $1.33/мес достигается в январе-феврале** почти наверняка —
для этого хватит пары сотен посетителей.

Вероятность, что сезон даст больше $100/мес — я оцениваю в 40–45%.
Вероятность, что проект вообще не взлетит и его надо будет закрыть — 35%.

Решение о закрытии стоит принимать **не раньше мая 2027**, когда пройдёт сезон.
Раньше данных просто не будет: сейчас сентябрь, а спрос на даты заморозков
появляется в феврале.

## Что сделано

- **Блок «Hail in {место}»** со ссылкой «Hail history in {место} →», без `nofollow`:
  - страница города `/storms/{slug}` — перед разделом «How to read this page».
    Ссылка: `https://myhailmap.com/hail/{st}/{city}?utm_source=stormsthathit&utm_medium=city`;
  - страница штата `/storms/state/{st}` — под таблицей городов, `utm_medium=state`.
- **Только штаты града:** TX, OK, KS, NE, CO, SD, ND, IA, MN, MO, WY, MT, NM (`HAIL_STATES` в `src/lib/hail.ts`).
  На страницах других штатов блока нет: ссылка про град на городе во Флориде не по смыслу.
- **Блок ставится, только если у города есть страница на myhailmap** (города от 10 тыс. жителей).
  Список снят с сайта и закоммичен в `src/data/hail-places.json`: 717 городов. Обновление — `npm run hail:places`.
  Так сборка не зависит от доступности чужого сайта.
- **Сопоставление названий:** «Saint Louis» = «St. Louis», «Lees Summit» = «Lee's Summit», «Canon City» = «Cañon City»
  (`cityKey`). Если в одном штате два города с одним названием, ссылку не ставим.
- **Покрытие:** ссылку получат 633 из 2 603 страниц городов в штатах града, плюс 13 страниц штатов.
  Без ссылки остались города меньше 10 тыс. жителей и населённые пункты без статуса города (Cypress TX, Kingwood TX и т. п.).

## Замер: ворота названы до выкладки

Период — 30 дней с выкладки. Источник — таблица `events` в D1 myhailmap.

| Переходов за 30 дней | Покупок | Решение |
|---|---|---|
| < 30 | — | канал не работает; ссылки оставить ради SEO |
| ≥ 30 | 0 | записать, где отваливаются: поиск или оплата |
| ≥ 30 | ≥ 1 | считать каналом; расширить блоки |

**Ограничение замера:** myhailmap пишет `city_view` с UTM только на страницах городов. Переход на страницу
штата (`utm_medium=state`) в `events` не попадает. Считаем по `utm_medium=city`; страниц штатов всего 13, потеря мала.

Запрос (из `projects/hail-maps/web`):

```sh
npx wrangler d1 execute hail-maps --remote --command "
  SELECT kind, COUNT(*) AS n, COUNT(DISTINCT sid) AS sessions
  FROM events
  WHERE sid IN (SELECT sid FROM events WHERE utm_source = 'stormsthathit')
  GROUP BY kind ORDER BY n DESC"
```

Строки `city_view` — переходы; `search`, `report`, `checkout`, `purchase`, `paid` — дальше по воронке.

- В sitemap 14 442 адреса, домену три недели. Google знает адреса, но не тратит на них бюджет сканирования.
  Это не ошибка сайта: кнопку «Проверить исправление» для этой строки не нажимать.
- Страницы не пустые: у 12 254 из 13 643 городов 16+ событий, 1–2 события только у 243 [И: база, 2026-10-02].
  Значит, причина — доверие к домену и однотипность шаблона, а не отсутствие данных.
- Рычаги по силе: внешние ссылки на сайт → перелинковка «соседние города по расстоянию» (сейчас малые
  города доступны только из большой таблицы штата) → уникальный текст на страницах крупных городов.

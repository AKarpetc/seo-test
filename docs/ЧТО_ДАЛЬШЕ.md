## 1. Домен (обязательно, блокирует деплой)

Нужно выбрать и зарегистрировать домен. Название имеет значение для SEO: сайт —
англоязычный справочник по данным госорганов США, поэтому домен должен быть
англоязычным и не привязанным к одной нише (у нас 7 разных справочников).

Варианты по смыслу: что-то вроде `usrecordlookup.com`, `openregistryus.com`,
`federaldirectory.com` — конкретное имя выбирать вам.

**Как:** AWS Console → Route 53 → Registered domains → Register domain.
Регистрация в Route 53 сразу создаёт hosted zone, ничего дополнительно настраивать не надо.
Стоимость `.com` — около $14/год.

**Что мне прислать:** имя домена и Hosted Zone ID (`Z...`, виден в Route 53 → Hosted zones).

## 2. Расширить права IAM (обязательно, 2 минуты)

Текущая политика `seo_user` не содержит трёх прав, без которых деплой упадёт.
AWS Console → IAM → Users → `seo_user` → политика → добавить в список `Action`:

```
"cloudformation:*",
"application-autoscaling:*",
"iam:CreateServiceLinkedRole"
```

## 3. Установить AWS CLI (обязательно, 2 минуты)

На вашем Mac его нет — из-за этого деплой сейчас невозможен даже технически.

```bash
brew install awscli
aws configure   # ключ, секрет и us-east-1 взять из .env
```

## 4. Бесплатные API-ключи (не блокирует, но открывает 3 ниши)

Четыре справочника построены, но пустые — государство закрыло эти источники ключами.
Код готов, нужен только ключ.

| Ниша | Где взять | Время |
|---|---|---|
| Демография по ZIP | https://api.census.gov/data/key_signup.html | 2 мин, ключ приходит на почту |
| Тарифы на электричество | https://www.eia.gov/opendata/register.php | 2 мин |
| Товарные знаки | https://data.uspto.gov/ — регистрация и запрос API-ключа | дольше, требует аккаунта |
| Интернет-провайдеры | https://broadbandmap.fcc.gov/data-download — требует аккаунт FCC | дольше |

Первые два — самые быстрые и самые ценные: данные Census перемножаются с уже
загруженными (например, «средний счёт за электричество для дома в 3 спальни в {город}»),
а это самый большой источник низкочастотных запросов.

**Что мне прислать:** ключи, я допишу загрузчики и залью данные.

## 5. Решение по бюджету

Два варианта архитектуры, оба готовы:

| Вариант | Что это | Цена/мес | Когда выбирать |
|---|---|---|---|
| **EC2 + docker-compose** | Один сервер, база рядом | ~$50 | Сейчас. Трафика пока нет |
| **ECS Fargate + RDS** | То, что в `infra/*.yaml` | ~$260 | Когда пойдёт трафик |

Моя рекомендация — начать с первого. Разница в $210/мес при нулевом трафике ничего не
покупает, а переезд на второй вариант потом делается за час, потому что CloudFormation
шаблоны уже написаны и провалидированы.

**Что мне сказать:** какой вариант.

## Что уже работает и чего ждать

Сайт собирается и отвечает локально на `http://localhost:3100`. Загружено 11.3 млн
записей. Но по срокам стоит быть реалистом: **11 млн страниц Google не проиндексирует
ни за месяц, ни за три.** Реальный сценарий — сотни тысяч страниц в индексе за первые
полгода, и то при условии, что страницы не будут признаны «тонкими».

Именно поэтому в загрузчиках стоят фильтры: неактивные врачи и перевозчики без
действующего разрешения не попадают в базу вообще, агрегатные страницы создаются только
при трёх и более провайдерах, а 1.9 млн брендовых продуктов USDA сознательно не
загружены. Эти ограничения снижают количество страниц, но это единственный способ не
получить фильтр за массовый мусор.

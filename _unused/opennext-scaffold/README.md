# Отложенное: обвязка @opennextjs/cloudflare

Эти файлы появились 14.09.2026 сами: `npx wrangler` увидел Next.js-проект
без конфигурации Cloudflare и развернул мастер OpenNext.

Они обслуживают деплой Next.js **как воркера** — путь, от которого проект
отказался в пользу статики на Pages. Здесь они лежат, чтобы не мозолить глаза
в корне, но и не пропасть, если к варианту с сервером всё же вернутся.

## Решение

Откат остальных следов мастера **сознательно отложен**, откатывать не нужно.
В рабочем дереве от него остались правки, которые никто не отменял:

| Файл | Что добавлено |
|---|---|
| `next.config.ts` | импорт `initOpenNextCloudflareForDev()` |
| `package.json` | `@opennextjs/cloudflare`, `wrangler`, скрипты `preview` / `deploy` / `upload` / `cf-typegen` |
| `package-lock.json` | ~13 тыс. строк следом за ними |
| `.gitignore` | правила для `.open-next`, `.wrangler`, `.dev.vars` |

Проверено после переноса: `npm run build` проходит, `npm run publish` выкладывает
сайты штатно. То есть обвязка лежит мёртвым грузом и ничему не мешает.

`public/_headers` намеренно **оставлен на месте**: он от того же мастера, но
полезен и уже уехал в обе выкладки — ставит `Cache-Control: immutable`
на `/_next/static/*`.
